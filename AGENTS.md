# Repository guidance

This repository publishes Ma Junhao's personal website with Valaxy and the Yun theme through GitHub Pages.

- Keep personal details and site metadata in `site.config.ts`.
- Keep pages and posts under `pages/`.
- Leave the personal introduction blank and the avatar empty unless Ma Junhao asks to fill them in.
- Use pnpm 9 and keep `pnpm-lock.yaml` in sync with `package.json`.
- The GitHub Pages workflow is `.github/workflows/pages.yml`.
