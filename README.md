# 天马要行空的个人网站

Built with [Valaxy](https://valaxy.site/) and the [Yun theme](https://valaxy.site/themes/yun), and published through GitHub Pages.

## Update content

- Edit `site.config.ts` for the site title and personal details.
- Edit `pages/index.md` and `pages/about/index.md` for the home and About pages.
- Add projects under `pages/projects/`.
- Add articles under `pages/posts/`.
- Edit `pages/cv.md` for the résumé.

## Local preview

```sh
pnpm install
pnpm dev
```

Pushing changes to `master` automatically builds and deploys the site.
